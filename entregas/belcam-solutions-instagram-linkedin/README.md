# Belcam Solutions — quatro novos posts com retrato

Quatro temas, cada um com uma arte vertical para Instagram e uma composição horizontal para LinkedIn. A numeração 13 a 16 dá continuidade aos posts anteriores da Belcam Solutions.

**[Baixar as oito artes e as legendas em ZIP](Belcam-Solutions-Instagram-LinkedIn.zip?raw=true)**

- [Legendas para Instagram](legendas-instagram.md)
- [Legendas para LinkedIn](legendas-linkedin.md)

As imagens estão em JPG, RGB, com tamanho reduzido para facilitar o carregamento. Os retratos foram compostos a partir das fotos fornecidas, seguindo o azul da marca.

LinkedIn: **1734 × 907 px**, horizontal próximo de 1,91:1.
